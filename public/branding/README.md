# Next Flow Brand Guide

## Brand Positioning
Next Flow is a modern multi-tenant workspace for project and task management, built for clear collaboration and continuous delivery.

## Core Palette
- Midnight Navy: `#0b1f3a`
- Flow Teal: `#0b7285`
- Signal Cyan: `#22d3ee`
- Frost Mint: `#99f6e4`
- Neutral Ink: `#0f172a`

## Typography Direction
- Primary sans: Inter / Geist / clean geometric sans-serif
- Wordmark style: uppercase, bold, high legibility

## Brand Assets
- Logo mark: `/branding/next-flow-mark.svg`
- Full logo: `/branding/next-flow-logo.svg`
- Favicon: `/favicon.svg`

## Usage Notes
- Use the logo mark for compact surfaces (favicon, app switcher, avatar).
- Use the full logo for landing pages, docs headers, and social previews.
- Keep generous spacing around the mark to preserve recognition at small sizes.
